## Hướng dẫn chạy nhanh

Từ thư mục gốc `Lab02`:
```bash
npm run dev
```
Hoặc di chuyển trực tiếp vào `orchid-gallery-spa`:
```bash
cd orchid-gallery-spa
npm install
npm run dev
```

Kiểm tra production build:
```bash
npm run build
npm run preview
```

Chi tiết tài liệu, giải thích kiến trúc phân tầng, phân tích cơ chế Caching TTL 30s, so sánh Fetch vs Axios, và bộ câu trả lời 20 câu hỏi **Human Verification Gate** được trình bày đầy đủ tại:
